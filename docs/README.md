# Framework Documentation

This directory contains technical design documentation, architecture diagrams, and specification references for the Email TLS Passive Forensics Framework.

## Documents
- [`architecture.md`](file:///Users/teenamunjal/sih2/docs/architecture.md): Technical breakdown of the ingestion pipeline, TLS inspection, ML & SHAP explainability model, and reporting framework.

## Key Compliance Standards Monitored
1. **NIST SP 800-52 Rev. 2**: Guidelines for the Selection, Configuration, and Use of Transport Layer Security (TLS) Implementations.
2. **PCI-DSS v4.0 Requirement 4.2**: Strong cryptography for transmission of cardholder data across open, public networks.
3. **RFC 8314**: Cleartext Considered Obsolete: Use of Transport Layer Security (TLS) for Email Submission and Access.
4. **CIS Benchmarks**: Recommended security configurations for mail infrastructure TLS ciphers and certificates.
